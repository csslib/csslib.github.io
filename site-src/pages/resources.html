Standards

Specifications

Where CSS is defined. Editor's drafts show the latest thinking; the W3C pages show what is stable.

  • W3CCSS home at the W3CThe W3C's starting point for CSS: news, the list of modules and how the language is developed.↗
  • W3CCSS current workEvery CSS module with its maturity level, from early drafts to finished recommendations.↗
  • W3CCSS Snapshot 2026The official definition of what “CSS” means today: which modules are stable and which are ready to use.↗
  • CSSWGCSS editor's draftsThe live, up-to-date text of every CSS specification, edited as the working group makes decisions.↗
  • CSSWGCSS Working Group on GitHubWhere new features are proposed and debated in public. Anyone can read the issues and join in.↗
  • WHATWGHTML Living Standard: popoverThe HTML side of popovers, the attribute that powers top-layer menus and tooltips.↗

  • W3C WebDXWeb Platform StatusSearchable Baseline status and test results for every web feature, kept up to date automatically.↗
