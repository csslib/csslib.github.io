FAQ

Questions, answered.

Is Atelier free?

Yes. Every studio is free and open source under the MIT License. There is no sign-up and no paid tier.

Do I need to install anything?

No. Each studio opens straight in your browser.

What do the studios export?

Plain, framework-free CSS (and semantic HTML for layouts) that you can paste into any project, framework or design system.

Is my work uploaded anywhere?

No. Everything happens on your own device; the studios only hand you code to copy.

Which browsers are supported?

Current versions of Chrome, Edge, Safari and Firefox. The studios are designed for desktop screens and adapt down to tablets and phones.

How does Atelier relate to csslib?

Atelier is one of the projects in csslib, a collection of open-source CSS projects that also includes the Vektor.css charting library.
