Specimen Lab

Put any visual CSS property under the microscope.

Specimen Lab is a hands-on playground for 32 visual CSS properties. Drag handles right on the stage, read how the browser really computes each value, and copy the exact declaration when it looks right.

Features

What you can do in Specimen Lab.

01

32 visual properties

From clip-path and border-radius to shadows, filters, transforms, typography, flexbox, grid and scroll snap, in ten categories.

02

Hands-on gizmos

Drag polygon vertices, corner handles, angle dials, shadow offsets and Bézier points directly on the stage.

03

Mental models

Each property explains how the browser actually computes it, with the full syntax broken down piece by piece.

04

Gotchas & pro tips

Learn the traps, such as clip-path cutting off box-shadow, before they cost you an afternoon.

05

32 challenges

A small hands-on goal for every property turns exploring into learning, and your progress is tracked as you go.

06

Copy-ready code

Copy the exact declaration or a complete class, and search the directory to jump to any property.

How it works

Four steps to production CSS.

  1. Pick a property

    Browse ten categories or search the directory.

  2. Drag & tune

    Use on-stage handles, sliders and presets.

  3. Understand it

    Read the mental model, syntax and gotchas.

  4. Copy the CSS

    Grab the declaration or a full class.

The output

Exactly the declaration you see

What is on the stage is what you copy. Specimen Lab writes plain declarations you can paste into any stylesheet, component or design system.
