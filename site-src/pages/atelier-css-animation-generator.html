Features

What you can do in Kinetix Studio.

01

Visual node graph

Start from a trigger and chain animation steps with wires, so the whole sequence reads as a flowchart instead of a wall of delays.

02

Parallel branches & sync

Fire several elements at once, then hold the next step until every branch has finished. Kinetix works out the delays for you.

03

Per-breakpoint routing

A width-range router sends different motion to mobile, tablet and desktop, and the export writes the @media queries.

04

Keyframe & easing editor

Tune translate, scale, rotate, opacity, blur and colour at every keyframe stop, and shape timing with a cubic-bezier curve editor.

05

Live responsive stage

Preview on a realistic page that uses your own element IDs, drag the viewport width and replay whenever you like.

06

Reduced-motion aware

Simulate prefers-reduced-motion and export a respectful fallback alongside the full animation.

How it works

Four steps to production CSS.

  1. Pick a starting flow

    Load a preset sequence or start from a single trigger.

  2. Wire the sequence

    Add steps, branch them in parallel and set width ranges.

  3. Tune the motion

    Edit keyframe stops, durations and easing curves.

  4. Export the CSS

    Copy or download keyframes, selectors and media queries.

The output

Readable keyframes, ready for production

Kinetix writes the same CSS you would write by hand: named @keyframes, one animation shorthand per element, media queries for each width range and a reduced-motion block.

Great for

  • Hero entrances
  • Staggered card reveals
  • Navigation drops
  • Responsive motion systems
Example export
@keyframes kx-hero-rise {
  0%   { opacity: 0; transform: translateY(24px) scale(0.96); filter: blur(6px); }
  100% { opacity: 1; transform: translateY(0) scale(1); filter: blur(0); }
}

#hero-heading {
  animation: kx-hero-rise 620ms cubic-bezier(0.22, 1, 0.36, 1) 40ms both;
}

@media (max-width: 639px) {
  #hero-heading { animation-duration: 420ms; }
}

@media (prefers-reduced-motion: reduce) {
  #hero-heading { animation: none; }
}
