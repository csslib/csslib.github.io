FAQ

Questions, answered.

What is csslib?

csslib is a home for free, open-source CSS projects. Each project is independent: use the visual studios in Atelier, drop Vektor.css into a page, or take just the parts you need.

Is everything free?

Yes. Every project is released under the MIT License, with no sign-up and no paid tier.

Do I need a build step or framework?

No. The studios run in your browser and export plain CSS, and the libraries are single stylesheets you link from any page.

What is coming next?

More studios, libraries and experiments built on modern native CSS. Follow along on GitHub.
