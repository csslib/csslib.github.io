About

A home for open-source CSS projects.

csslib collects free tools and libraries that make modern CSS easier to see, learn and ship. Every project runs in the browser with nothing to install, and every one hands back plain code you can paste anywhere.

The projects

  • Atelier, four visual CSS studios that turn motion, colour, form and layout into hands-on tools.
    • Kinetix Studio — CSS animation generator
    • ChromaFlow — CSS gradient generator
    • Specimen Lab — CSS property playground
    • IntrinsicFlow — CSS Grid & Flexbox layout builder
  • Vektor.css, an independent charting library that draws bar, radar, heatmap, donut, gauge, funnel and box-plot charts in pure CSS.

More projects will join csslib over time.

How the projects are made

The pages are plain HTML and CSS served as static files, with small Lit web components where a tool needs interaction. There is no build step and no account, and nothing you design is uploaded: every tool works on your own device and only gives you code to copy.

Open source

Every csslib project is released under the MIT License. Use it, change it and ship it in your own work.

Get in touch

Questions, bug reports and ideas for new projects are all welcome. Reach out on LinkedIn or GitHub, or use the email button.
